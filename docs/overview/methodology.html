Overview

The objective of this project is to derive reproducible regional sea-ice statistics from the daily passive microwave sea-ice concentration products published by the National Snow and Ice Data Center (NSIDC).

Rather than analysing the complete Arctic Ocean, the workflow focuses on the Hudson Bay system and several predefined subregions. Every processing step is fully deterministic and can be reproduced directly from the original GeoTIFF products.

Scientific Background

Hudson Bay is one of the world's largest seasonally ice-covered inland seas. Sea ice usually begins to form during autumn, reaches its maximum extent during late winter and melts again throughout spring and summer.

Monitoring this seasonal cycle provides valuable information for climate research, marine ecosystems, operational ice forecasting and navigation. Long-term observations also reveal interannual variability and changing freeze-up and break-up behaviour.

Sea Ice Concentration Processing

The NSIDC Climate Data Record stores sea ice concentration as scaled integer values together with several special classification codes. Prior to any statistical analysis these values are converted into physically meaningful fractional sea ice concentrations.

Valid Range

0–1000

Scaling

Value ÷ 1000

Output Range

0.0 – 1.0

Value Meaning
2510 Pole hole
2530 Coast
2540 Land
2550 Missing data
Processing logic 
ice[ice > 1000] = np.nan

ice /= 1000.0

Processing Stages

1. Reading the Dataset

Daily observations are provided as GeoTIFF raster files in the NSIDC Polar Stereographic projection (EPSG:3411). Rasterio is used to access both the pixel values and all associated spatial metadata.

Implementation 
with rasterio.open(filename) as src:

    ice = src.read(1)

    transform = src.transform

    profile = src.profile

2. Metadata Validation

Each dataset is validated before further processing. Raster dimensions, projection information and affine transformations are verified to ensure that all observations are spatially consistent throughout the historical time series.

3. Data Cleaning

Special NSIDC classification values representing land, coastlines, missing observations and the polar data gap are removed before numerical processing begins.

Implementation 
ice[ice > 1000] = np.nan

ice /= 1000.0

4. Regional Analysis

Configurable GeoJSON polygons are converted into raster masks. These masks identify all pixels belonging to each analysis region and allow efficient daily processing without repeatedly evaluating polygon geometries.

5. Statistical Analysis

Relative sea ice concentration and absolute ice-covered area are computed for every configured region before the historical database is updated.

6. Export

Results are written to a continuously growing CSV archive and the newest observation is exported separately as a compact JSON document used by the GitHub Pages showcase.

Regional Analysis

Five configurable polygon regions are analysed independently. This allows the seasonal evolution of different parts of the Hudson Bay system to be studied separately while maintaining a consistent methodology.

  • Hudson Bay Area
  • Hudson Bay
  • Foxe Basin
  • Gulf of Boothia
  • Hudson Strait

Region Mask Generation

Each analysis region is defined by a configurable GeoJSON polygon rather than hard-coded raster indices. During processing these polygons are transformed into raster masks matching the NSIDC grid.

Input

  • GeoJSON polygons
  • EPSG:3411 projection
  • Raster geometry

Output

  • Boolean raster mask
  • Pixel lookup
  • Reusable cache

The generated masks are cached and reused for all subsequent observations, making daily processing essentially independent of polygon complexity.

Regional Statistics

Two complementary quantities are computed for every analysis region.

Relative Coverage

Mean fractional sea ice concentration across all valid pixels.

Absolute Coverage

Fractional concentration multiplied by the area represented by every raster cell (625 km²).

Concept 
relative coverage

↓

mean concentration

↓

absolute coverage

=

concentration × pixel area

(pixel area = 625 km²)

Reproducibility

Raw Data

Original NSIDC GeoTIFF products remain unchanged.

Configuration

Region definitions and processing parameters are stored separately from the analysis code.

Derived Results

Statistics and figures can always be regenerated from the original data.

Current Limitations

  • Daily passive microwave observations only
  • No climatological anomaly calculations yet
  • No uncertainty estimates currently provided
  • No atmospheric or oceanographic variables included
