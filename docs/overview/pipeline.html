Processing Pipeline

This page describes the complete automated workflow used to transform daily NSIDC sea-ice concentration products into reproducible scientific statistics and publication-quality visualizations.

Overview

The Hudson Bay Sea Ice Analysis project provides a fully automated and reproducible Python workflow for downloading, processing, analysing and visualising daily satellite-derived sea-ice concentration data.

The pipeline is designed around incremental processing. Existing observations are never analysed twice, allowing daily updates to finish within only a few seconds whenever no new observations have been published by the National Snow and Ice Data Center (NSIDC).

Pipeline Stages

1. Download

Synchronises the local archive with the latest NSIDC GeoTIFF products and downloads only observations that are not yet available locally.

2. Validation

Each GeoTIFF is checked for projection, dimensions, metadata and data integrity before further processing.

3. Regional Analysis

Configurable polygon masks are applied to compute sea-ice concentration statistics for five Hudson Bay subregions.

4. Results

Daily statistics are appended to a historical CSV database while the most recent observation is exported as a compact JSON file for dashboards.

5. Visualisation

Publication-quality overview maps, seasonal time series and polar plots are generated automatically.

6. Publication

The generated figures and metadata are exported to the GitHub Pages showcase where the latest products become immediately available.

Reproducibility

All generated statistics and visualisations are derived directly from the original NSIDC GeoTIFF products without modifying the source data. Configuration, analysis, derived datasets and generated figures are stored separately to ensure complete transparency and reproducibility.
