Overview

The Hudson Bay Sea Ice Analysis project provides a fully automated and reproducible Python workflow for downloading, processing, analysing and visualising daily satellite-derived sea-ice concentration data.

The pipeline is designed around incremental processing. Existing observations are never analysed twice, allowing daily updates to finish within only a few seconds whenever no new observations have been published by the National Snow and Ice Data Center (NSIDC).

Command Line Interface

The processing pipeline is divided into a small number of independent command-line stages. Each stage can be executed individually during development or combined into a fully automated workflow using the update command.

⬇ Download

python src/main.py download

Synchronises the local archive with the NSIDC data repository and downloads only observations that are not yet available locally.

Typical use
  • Initial download of the complete dataset
  • Synchronise with newly published observations
  • Verify local data availability

⚙ Process

python src/main.py process

Processes all newly downloaded GeoTIFF files and updates the historical sea-ice database.

Generated files
  • output/analysis/ice_coverage_summary.csv
  • output/analysis/latest.json

📈 Plots

python src/main.py plots all

Generates publication-quality figures for every analysis region.

Examples 
python src/main.py plots overview

python src/main.py plots timeseries

python src/main.py plots polar

python src/main.py plots all

🔄 Update

python src/main.py update

Recommended command for daily operation. Runs the complete incremental workflow, regenerates all figures and rebuilds the GitHub Pages website.

Executed stages
  • Download missing observations
  • Process new GeoTIFF files
  • Update CSV database
  • Generate all plots
  • Build GitHub Pages

Typical Workflows

First Installation

python src/main.py download

python src/main.py process

python src/main.py plots all

python src/main.py build

Creates the complete local archive, computes all historical statistics, generates every figure and builds the website.

Daily Update

python src/main.py update

For routine operation only this command is required. The update pipeline downloads only newly available observations, updates the analysis database and regenerates the website automatically.

Reproducibility

All generated statistics and visualisations are derived directly from the original NSIDC GeoTIFF products without modifying the source data. Configuration, analysis, derived datasets and generated figures are stored separately to ensure complete transparency and reproducibility.
