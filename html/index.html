Hudson Bay Sea Ice Analysis

A fully automated Python pipeline for downloading, processing and visualizing daily satellite-derived sea ice concentration in the Hudson Bay region.

Project Overview

The Hudson Bay Sea Ice Analysis project provides a reproducible scientific workflow for analysing daily sea ice concentration products published by the National Snow and Ice Data Center (NSIDC).

The complete pipeline automatically downloads new satellite products, performs geospatial analysis, computes regional sea ice statistics and generates publication-quality figures together with GitHub Pages updates.

Main Components

Download

Automatic synchronization with the NSIDC archive.

Processing

Rasterio, Cartopy and GeoJSON based regional analysis.

Analysis

Relative and absolute sea ice coverage for predefined regions.

Visualisation

Daily maps, time series and polar plots.
