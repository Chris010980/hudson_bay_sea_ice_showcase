Test Model and Suite

The project uses a five-level test model:

  • unit tests,
  • component tests,
  • integration tests,
  • end-to-end tests,
  • regression tests.

The mandatory CI quality gates run on every change: lint (ruff check), format (ruff format --check) and the test suite with coverage (pytest --cov=src). Dead-code analysis (vulture with a documented whitelist) runs advisingly.

Maintenance

This snapshot is updated on the development side whenever findings, test counts or coverage change — it is committed website source, not generated content, and the daily update workflow never touches this page.
